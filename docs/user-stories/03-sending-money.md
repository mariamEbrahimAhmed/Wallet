# Sending Money

- As a user, I want to send money to another user by their email or ID, so I can pay or transfer funds to them.
- As a user, I want to be blocked from sending more money than my current balance, so I can't go negative.
- As a user, I want to be blocked from sending a negative or zero amount, so the system can't be abused.
- As a user, I want to be blocked from sending money to myself, so transfers stay meaningful.
- As a user, I want to know immediately if a transfer fails (e.g. insufficient funds, invalid recipient), so I understand what went wrong.
